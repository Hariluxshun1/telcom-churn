# Working together

1. Never commit straight to `main`.
2. Make your own branch: `git checkout -b yourname/short-topic` (e.g. `ID2466/eda`).
3. Commit small and often, with clear messages.
4. Push your branch and open a Pull Request. One teammate reviews before merging.
5. Pull before you start work: `git checkout main && git pull`.
6. One notebook per stage, so two people rarely edit the same file.
